# Спецификация: Сохранения и поставка

> Статус: DRAFT. Формат файла и платформа подлежат подтверждению.

## Требования

### Requirement: Сохранение эксперимента

Если сохранение включено в утверждённый MVP, система SHALL сохранять конфигурацию эксперимента в версионируемом локальном формате.

#### Scenario: Загрузка несовместимого файла
- WHEN пользователь открывает файл неизвестной или неподдерживаемой версии
- THEN система сообщает о несовместимости и не перезаписывает файл автоматически

### Requirement: Поставка Windows-сборки

Если Windows x64 подтверждён как целевая платформа, репозиторий SHALL предоставлять автоматизированную сборку приложения и архив со всеми файлами, необходимыми для запуска без установленного Godot.

#### Scenario: Скачивание релиза
- WHEN пользователь скачивает архив Windows-релиза и распаковывает его
- THEN приложение запускается на поддерживаемой версии Windows без установки Godot Editor
