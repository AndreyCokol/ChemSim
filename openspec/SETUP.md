# Установка OpenSpec для локальной работы

OpenSpec состоит из двух частей:

1. **CLI** — устанавливается на рабочую машину пользователя.
2. **Артефакты проекта** — конфигурация, спецификации и change-пакеты, хранящиеся в Git. Эта часть уже добавлена в репозиторий.

## Windows

Открой PowerShell в локальной копии репозитория и установи официальный CLI:

```powershell
irm https://openspec.dev/cli/install.ps1 | iex
```

Проверь установку:

```powershell
openspec --version
```

Затем зарегистрируй интеграцию Codex (OpenSpec использует skills в `.agents/skills/`):

```powershell
openspec init --tools codex
```

Если проект уже инициализирован и нужно только обновить сгенерированные файлы интеграции:

```powershell
openspec update
```

## Важно

- Не устанавливай CLI через npm, если standalone installer сработал. Альтернативный способ: `npm install -g @fission-ai/openspec@latest`; он требует актуальный Node.js (порог версии смотри в официальной документации).
- Команды выше выполняются в локальном терминале на компьютере разработчика. GitHub API позволяет положить конфигурацию и документы в репозиторий, но не устанавливает глобальную программу на компьютер.
- OpenSpec CLI инициализацию интеграции нужно проверить по фактически созданным файлам `.agents/skills/openspec-*/SKILL.md`.
- Проектные требования и вопросы находятся в `openspec/`. Не начинай реализацию до согласования блокирующих решений в `openspec/changes/define-chemsim-mvp/questions.md`.

Официальная документация: https://openspec.dev/docs/installation
