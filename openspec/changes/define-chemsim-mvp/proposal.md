# Change: Определить MVP ChemSim

## Почему

Нужно определить проверяемый объём первой версии настольного симулятора химических реакций до разработки игрового кода. Сейчас репозиторий пуст, а ключевые продуктовые решения — целевая аудитория, область химии, уровень научной строгости и модель редактирования — требуют подтверждения владельца продукта.

## Цель

Согласовать MVP, который позволяет пользователю собрать эксперимент из веществ и реакций, задать начальные условия, запустить моделирование и интерпретировать изменение концентраций во времени.

## Предлагаемый объём MVP (черновик)

- 2D desktop-приложение на Godot 4.x для Windows x64.
- Лабораторная рабочая область с набором веществ и реакций.
- Настройка начальных концентраций, температуры и длительности эксперимента.
- Запуск, пауза, продолжение и сброс симуляции.
- Графики концентраций во времени и просмотр текущих значений.
- Редактирование пользовательских веществ и реакций в рамках выбранной области химии.
- Сохранение и загрузка экспериментов в локальный файл.
- Поставка готовой Windows-сборки архивом из GitHub Releases.

## Не входит в MVP (предварительно)

- 3D-молекулярная визуализация и квантово-химические расчёты.
- Полноценный промышленный химический пакет с гарантированной научной точностью.
- Облачные аккаунты, совместная работа и серверное хранение.
- Мобильная версия и macOS/Linux релизы.

## Принципы

1. Не подменять научную модель красивой анимацией: численная модель и ограничения должны быть явными.
2. Не заявлять точность без выбранной области применимости, допущений и валидационных тестов.
3. Все ключевые значения показывать с единицами измерения.
4. Не допускать отрицательных концентраций из-за численной ошибки.
5. Любое неподдерживаемое или некорректное состояние эксперимента объяснять пользователю.
