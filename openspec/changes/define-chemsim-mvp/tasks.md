## Правила
- Каждая задача имеет одного primary owner; зависимости между агентами записываются явно.
- Не менять чужие публичные DTO и спецификации без согласования.
- Не выдумывать численные константы, эталонные значения или лицензии.
- Отсутствие данных блокирует только тот расчёт, которому эти данные обязательны; неполная пользовательская запись может сохраняться.
- Реализация не начинается до явного утверждения владельцем.
