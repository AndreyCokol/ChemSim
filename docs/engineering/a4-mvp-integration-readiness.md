## 3. Exact A4 consumer semantics proposed for review (not a DTO freeze)

1. **Input identity:** Unique, stable, nonblank network species IDs and reaction IDs/revisions; all referenced stoichiometric and kinetic-order species must be network members. Parsing/chemical identity and charge/element validation belong upstream. A4 domain checks do not replace an element/charge balancer.
2. **Kinetic basis:** A4 currently accepts a volumetric power law `r=k × ∏cᵢ^αᵢ`, with separately provided finite non-negative orders. Required dimension: `[k]=(mol·m⁻³)^(1−Σα)·s⁻¹`; `s⁻¹` is not universal. The local `RateConstant(Value, ConcentrationExponent)` **does not contain** unit ID, T, Ea, source/provenance, uncertainty, applicability or law version. An upstream typed adapter must validate all of those; missing/unknown or incompatible information **blocks** the selected calculation rather than defaulting to zero or a guessed unit.
3. **Time/amount:** Exact initial amounts for every network species in mol, finite nonnegative; volume in m³ positive; finite start/end/output step in s; fixed volume and isothermal-only semantics. Block unsupported open flows, reverse kinetics, temperature-varying models or finite mixing; never silently downgrade them to this closed irreversible solver.
4. **Result and status:** `SimulationResult.Status == Success` is the only completed-trajectory indicator. A non-success status may include **valid prefix samples** and accepted/rejected/RHS counters; the unfinished interval is **not published**. A5 must show incomplete/failed reason, last valid timestamp and message, not extrapolate a complete graph to requested end time.
5. **Series:** Returned samples are time (s) + species amounts (mol). Concentration (mol/m³) is derived from amount/known fixed volume; A4 does not currently return rate/temperature/error-band/event/replay series. Do not invent missing time series; isothermal T(t) is model metadata when explicitly supplied upstream, not proof of computed thermal evolution.
6. **Reliability:** Numerical success, chemical conservation, scientific model validity, data quality and completeness are **separate** axes. Shared `ErrorEnvelope`, `ReliabilityVector`, unit registry, sample validity and schema version remain integrator decisions.

## 5. Concrete acceptance scenarios for integrator / A5 (proposed, not executable yet)

1. **A→B success:** A2 balanced signed-stoichiometry source + stable species IDs, explicitly supplied first-order k/orders, typed initial mol/volume m³; A4 reproduces `A(t)=A0 exp(-kt)`, valid A+B conservation, and A5 renders only validated samples through a confirmed execution bridge.
2. **Missing rate law / bad units:** Balanced text without independent kinetic order/k, unknown units or missing volume is **blocked before simulation**. Never infer k from arrow, order from balance, or zero from missing.
3. **Equilibrium-only input:** Reversible arrow plus thermodynamic K without kinetic law can at most invoke an approved A3 equilibrium solve, **not** A4 time kinetics.
4. **Identity or conservation mismatch:** Unstable parser-local ID, unresolved phase/species reference, missing initial amount, bad atom/charge balance or source-revision mismatch causes attributed failure, not a guessed mapping.
5. **Partial result:** Global step budget, cancellation or numerical failure after some full intervals returns a valid prefix with non-success status/counters. UI shows last valid time and does not plot the missing tail or mark Completed.
6. **No atom/charge law:** Numerical Success without validated external invariant set must not be shown as scientific conservation verification.
7. **Unsupported replay/flows:** UI leaves rewind/step/open flows disabled or labels them unsupported until event/replay semantics and integration are verified.
