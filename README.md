# ChemSim

Офлайн-симулятор химических экспериментов на Godot 4.x для Windows 10/11 x64.

## Текущий статус

Реализация начата после явного подтверждения владельцем OpenSpec baseline. Текущий срез — технический каркас приложения и парсер простых химических формул. Это **не** готовый химический симулятор: равновесие, кинетика, балансировщик и справочные данные пока не реализованы.

## Запуск

1. Установите Godot 4.x.
2. Откройте в Godot файл `project.godot`.
3. Нажмите Run Project.

## Проверка парсера

Из корня проекта:

```sh
godot --headless --path . --script res://tests/test_formula_parser.gd
```

## Ограничения текущего парсера

- Простые формулы и вложенные круглые группы.
- Фазы `(s)`, `(l)`, `(g)`, `(aq)`.
- Явный заряд с кареткой: `SO4^2-`, `Fe^3+`; краткая форма `H+` для однозарядных частиц.
- Неоднозначная форма вроде `Fe3+`, гидраты, комплексы и структурные формулы отклоняются.
- Стехиометрические коэффициенты и уравнения реакций пока не разбираются.
